# Social media drafts

One Markdown file per campaign, named `<YYYY-MM-DD>-<slug>.md`, produced by Codex according
to [docs/CODEX-BRIEF.md](../../docs/CODEX-BRIEF.md). Each file holds the captions per
channel and language, hashtags, the asset path under `public/posts/` and the intended
posting time in Yerevan time. Files here are drafts for the owner to publish; nothing posts
automatically.
